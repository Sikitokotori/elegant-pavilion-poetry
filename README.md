# 风雅阁 · 诗词一句

> 一屏水墨，一句诗。点一下，换一句。

横屏桌面小挂件：水墨山水铺底，半透明宣纸卡托住诗文，下方一枚朱印。
点「求一句」随机取一句古诗词，也可以开「自动觅句」让它每 2 秒自己换。

**零第三方依赖**——只用 Python 标准库和 Tkinter，断网也能用。

---

## 界面

- **背景**：同目录的 `水墨背景.png`，整数倍降采样后居中铺满 889 × 500
- **宣纸卡**：托住正文与出处，高度跟着文字自动收放
- **正文**：楷体，长句在卡片内自动换行，不会越界
- **朱印**：`求 一 句`
- **自动**：`▷ 自动觅句`，点一下开始每 2 秒轮换，再点暂停

## 运行

```bash
python 诗词一句.py
```

要求：

- Python 3.7+（Tkinter 随官方安装包自带；Linux 上需要 `sudo apt install python3-tk`）
- `诗词一句.py` 与 `水墨背景.png` 放在同一目录
- 字体依赖系统楷体（Windows 自带；macOS / Linux 需自备，否则回落到默认字体）

## 几个实现上的取舍

**线程与界面隔离**
Tkinter 不是线程安全的，子线程直接操作控件会闪退。所以取词全部放在 daemon 线程里跑，
结果塞进 `queue.Queue`，主线程用 `after(60)` 轮询取出来再更新画面——网络再慢，界面也不会卡住。

**三级降级**
按 SaintIC 古文库 → 今日诗词的顺序尝试，单次请求 4 秒超时，慢就直接放弃换下一个；
两个都挂掉才落到内置的 30 多条经典名句。所以断网也能点出句子。

**防重入**
`_busy` 锁配合按钮置灰「觅 句 中 …」，连点不会堆出一串请求；自动模式下上一拍没回来就跳过这一拍。

**纯标准库缩放**
没有用 PIL，靠 `PhotoImage.subsample(k, k)` 做整数倍降采样，按背景图尺寸自动算 k，换来零依赖。

**卡片自适应**
`_fit_card()` 取正文与出处的联合包围盒，四周留 26 px 内边距重画宣纸卡，
长句换行后卡片会自己变高，不会盖住文字。

## 自己改

- **加句子**：编辑 `CLASSICS` 列表，格式 `["正文", "作者《篇名》"]`，本地兜底就用这份
- **换背景**：替换 `水墨背景.png` 即可，横图效果最好，尺寸随意（代码会自动缩放）
- **改窗口尺寸**：改 `W, H`，背景图比例跟着调整
- **调轮换频率**：`_auto_tick()` 里的 `after(2000, ...)`

## 已知限制

- 在线诗句来自公开免费接口，可能随时失效；失效时自动转用本地名句库，不影响使用
- 只在 Windows 上验证过，其他系统需确认楷体字体是否存在
- 背景图 2.7 MB 直接入库，介意仓库体积可以压缩后再提交
